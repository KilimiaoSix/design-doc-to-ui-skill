## Design Constraints Extracted

- Platform-native styles should not break familiar navigation or interaction paradigms.
- Expressive styles need larger controls, clear labels, and high-contrast containment to stay usable.
- Dark, glass, neumorphic, and brutalist styles require extra readability checks.
- Commerce styles need product imagery, filter/sort, gallery, cart, checkout, and confirmation states.
- AI assistant styles need prompt input, context cards, generated artifacts, citations/sources, and human-in-control affordances.
- Cross-device style samples must preserve one design language while adapting density and layout per endpoint.
