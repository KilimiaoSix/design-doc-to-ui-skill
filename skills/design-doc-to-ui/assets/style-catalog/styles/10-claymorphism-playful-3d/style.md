# Claymorphism Playful 3D

## Intent

Friendly 3D interface style for learning, habits, rewards, family apps, onboarding, and gamified productivity where warmth and motivation are part of the product value.

## Visual Language

- Puffy rounded cards, inflated buttons, and matte clay-like surfaces.
- Bright but soft palette with sky blue, peach, lemon, mint, lavender, and coral.
- Small mascots and reward objects used as supporting UI elements.
- Large touch targets, playful icons, progress rings, rewards, and activity cards.

## Endpoint Adaptation

- Web: family goals dashboard with activity cards, reward widgets, and progress chart.
- PC: learning workspace with lesson cards, task list, collection, and buddy panel.
- Mobile: daily habit tracker with large status card, stacked tasks, and bottom navigation.
- Tablet: activity planner with schedule, progress, rewards, and friends panel.

## Prompt Guidance

Ask for claymorphism as a real app UI, not a character poster. Specify toy-like 3D cards, puffy controls, soft shadows, matte surfaces, friendly small mascot elements, and endpoint-specific layouts.

## Negative Constraints

Avoid pure mascot illustration, landing page art, harsh brutalist borders, glass panels, flat bento grids, tiny copy, and decorative scenes that crowd out the UI.

## Risks

- 3D surfaces and mascots can overwhelm task clarity if overused.
- Colorful cards need contrast checks for text and controls.
- Production systems should define when 3D assets are decorative versus interactive.
