# 19 AI Assistant Copilot

Sample: `../../generated-samples/19-ai-assistant-copilot-style-board.png`

## Style Summary

AI assistant copilot UI centers on conversational work, contextual suggestions, source grounding, and artifact previews. It should feel calm and trustworthy while still making generated outputs, citations, and next actions easy to inspect.

## Visual Language

- White and cool gray surfaces with charcoal text, electric blue actions, teal assistant accents, soft lavender highlights, and small amber status accents.
- Chat threads, prompt composers, suggestion chips, context cards, source/citation chips, and generated artifact previews.
- Subtle AI glow or assistant iconography used sparingly; avoid magical or abstract-only visuals.
- Strong separation between user input, model response, source evidence, and produced artifacts.
- Desktop and tablet layouts should use split panes for context plus output.

## Four-Endpoint Guidance

- Web: show chat, context cards, sources, and an artifact preview in a browser workspace.
- PC: place copilot beside an editor or document workspace to show in-context assistance.
- Mobile: focus on compact chat, quick suggestions, voice/action controls, and composer.
- Tablet: use split assistant and artifact/source preview with touch-friendly controls.

## Prompt Guidance

Ask for an AI productivity assistant with chat, prompt composer, suggestions, sources, citations, context cards, and artifact previews. Keep generated text as placeholder lines so the board emphasizes interface structure rather than fake AI output.

## Negative Constraints

Avoid abstract AI posters, excessive neon, unreadable code, fake long answers, hallucinated citations, brand logos, and interfaces where the assistant hides the user workflow.

## Accessibility Risks

Source chips and citation markers must remain readable and keyboard reachable. AI status, errors, and confidence cues should use explicit text, not just glow, color, or icon state.
