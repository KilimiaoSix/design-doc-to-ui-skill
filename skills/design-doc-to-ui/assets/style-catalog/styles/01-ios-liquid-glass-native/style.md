# 01 ios-liquid-glass-native

## Style summary

Native Apple-style application UI with translucent liquid glass surfaces, soft blur, shallow depth, rounded native controls, hairline separators, and calm high-contrast content. The style should feel like a real iOS/macOS family product, not a marketing page.

## Visual language

- Surfaces: frosted glass, white translucent panels, subtle material blur.
- Shape: large continuous corners, native button capsules, soft cards.
- Type: SF-like clean sans typography with limited labels.
- Color: clear glass, white, light gray, soft blue, mint, small warm accents.
- Interaction cues: compact icon rails, native sheet controls, status chips, chart cards.

## Four-end adaptation

- Web: broad browser-like dashboard with sidebar navigation.
- PC: desktop app frame with the same glass cards and command controls.
- Mobile: vertically stacked native cards with bottom navigation.
- Tablet: split layout that preserves the same card hierarchy at larger touch scale.

## Best fit

Consumer productivity, personal finance, wellness analytics, lightweight collaboration tools, and native-first products where polish and calm interaction matter more than data density.

## Constraints

Keep text minimal and readable. Avoid heavy gradients, dark chrome, dense enterprise tables, decorative poster layouts, or arbitrary branding.
