# 16 Education Playful

Sample: `../../generated-samples/16-education-playful-style-board.png`

## Style Summary

Education playful UI supports learning products that need to feel approachable, motivating, and easy to continue. It combines clear next steps with progress loops, badges, friendly illustration, and simple learning task surfaces.

## Visual Language

- Sky blue, mint, warm yellow, coral, off-white surfaces, and deep navy text.
- Rounded learning cards, progress rings, badges, quiz choices, and soft illustrated content.
- Friendly mascot or subject illustrations used as supporting content, not as the whole screen.
- Large controls and simple icon navigation for younger or mixed-age audiences.
- Clear primary actions such as start, continue, or next lesson.

## Four-Endpoint Guidance

- Web: show a broad learning dashboard with courses, recommendations, progress, and navigation.
- PC: support a larger lesson workspace with media, activity lists, and progress context.
- Mobile: prioritize one quiz, one next action, and compact progress feedback.
- Tablet: use interactive workbook layouts with drawing, drag/drop, or step-by-step learning content.

## Prompt Guidance

Ask for a learning app with progress, lessons, quiz choices, badges, and friendly subject imagery. Keep body text sparse and use placeholder lines for content-heavy areas so the generated board reads as UI rather than a poster.

## Negative Constraints

Avoid classroom stock posters, excessive mascots, illegible microcopy, random educational jargon, duplicated layouts, and decorative-only onboarding screens.

## Accessibility Risks

Playful colors can reduce contrast when used for text or status. Progress and reward states should not rely on color alone, and mobile quiz targets must remain large enough for touch.
