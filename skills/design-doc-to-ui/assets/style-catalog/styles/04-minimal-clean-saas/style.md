# 04 minimal-clean-saas

## Style summary

Minimal clean SaaS interface style for operational dashboards. It emphasizes restraint, readable hierarchy, light borders, compact density, practical controls, and neutral surfaces.

## Visual language

- Surfaces: white cards, light gray page background, thin borders.
- Shape: restrained 8px card radii, square-ish controls, compact tables.
- Type: neutral sans typography with clear hierarchy and limited display scale.
- Color: white, slate text, light gray borders, soft cyan, green status, small amber accent.
- Interaction cues: filters, KPI cards, tables, line charts, status chips, compact buttons.

## Four-end adaptation

- Web: broad SaaS dashboard with sidebar, KPIs, chart, and table.
- PC: desktop frame with the same analytical hierarchy.
- Mobile: summarized KPI and table/list modules stacked vertically.
- Tablet: wider touch layout preserving filters and data cards.

## Best fit

B2B analytics, admin consoles, CRM, billing, monitoring, revenue operations, support operations, and internal workflow tools.

## Constraints

Avoid hero imagery, oversized headings, decorative gradients, purple-dominant themes, and card-heavy marketing layouts. Prioritize scanning, comparison, and repeated use.
