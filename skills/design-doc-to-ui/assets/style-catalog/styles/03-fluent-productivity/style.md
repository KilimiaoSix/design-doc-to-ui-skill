# 03 fluent-productivity

## Style summary

Microsoft Fluent-inspired productivity UI with Mica/Acrylic-like surfaces, compact command bars, restrained blue accents, practical work-hub structure, and a focused enterprise tone.

## Visual language

- Surfaces: light gray Mica-style panels, soft depth, subtle borders.
- Shape: moderate radii, compact cards, crisp command surfaces.
- Type: Segoe-like interface typography with clear work labels.
- Color: cool white, Mica gray, productivity blue, small teal and purple accents.
- Interaction cues: command bars, navigation rail, list rows, calendar and file previews.

## Four-end adaptation

- Web: work hub dashboard with sidebar and content cards.
- PC: desktop productivity shell with command bar and window controls.
- Mobile: compressed work stream with card-based modules.
- Tablet: larger split productivity layout for reading and action.

## Best fit

Enterprise suites, internal tools, document workflows, inbox/task hubs, scheduling products, and collaboration-heavy applications.

## Constraints

Avoid copying brand marks. Use Fluent principles as an abstract product style: Mica depth, command bars, compact structure, and restrained color.
