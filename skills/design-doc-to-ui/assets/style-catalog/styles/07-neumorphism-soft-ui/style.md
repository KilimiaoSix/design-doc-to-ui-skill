# Neumorphism Soft UI

## Intent

Soft tactile UI for sparse planning, focus, habits, settings, or wellness dashboards where large controls and calm surfaces matter more than dense information.

## Visual Language

- Warm off-white surfaces with subtle raised and sunken shapes.
- Inner and outer shadows that make controls feel embossed.
- Pastel blue, coral, mint, and yellow accents.
- Rounded cards, large controls, gentle progress indicators, and quiet navigation.

## Endpoint Adaptation

- Web: spacious weekly planning dashboard with sidebar navigation and large card controls.
- PC: slightly denser project dashboard with schedule, progress, and quick actions.
- Mobile: stacked metrics and task cards with bottom navigation and large tap targets.
- Tablet: split planning and focus dashboard with roomy controls.

## Prompt Guidance

Use neumorphism only for interfaces with limited density and clear controls. Request soft inner and outer shadows, tactile raised and sunken components, pastel accents, large touch targets, and short labels.

## Negative Constraints

Avoid dense data grids, pure white-on-white ambiguity, glass effects, harsh shadows, saturated brutalist color, and tiny unlabelled icon-only controls.

## Risks

- Contrast and affordance can be weak; production components need explicit borders, focus states, and state color.
- Neumorphic shadows can make disabled and active states hard to distinguish.
- Works best on sparse dashboards; avoid using it for complex enterprise workflows.
