# 02 material-3-expressive

## Style summary

Google Material 3 Expressive application UI with bold rounded geometry, dynamic color, tonal surfaces, playful component scale, and adaptive layouts. The style should feel energetic but still operational.

## Visual language

- Surfaces: elevated rounded cards, tonal containers, clear background layering.
- Shape: extra-rounded cards, pill navigation, floating action buttons.
- Type: readable sans typography with compact app labels.
- Color: coral, cobalt blue, yellow, teal, off-white surfaces.
- Interaction cues: FABs, tonal buttons, task chips, navigation rail, material icon buttons.

## Four-end adaptation

- Web: broad planning dashboard with prominent cards and action affordances.
- PC: desktop app variant with the same tonal cards and command actions.
- Mobile: stacked cards and bottom navigation with a clear FAB.
- Tablet: two-column material layout with larger touch-friendly cards.

## Best fit

Team planning, consumer productivity, education, lightweight CRM, collaboration apps, and tools that benefit from warmth and approachability without becoming decorative.

## Constraints

Keep expressive color balanced by neutral surfaces. Avoid overusing large blobs, unreadable chips, brand logos, or poster-style headlines.
