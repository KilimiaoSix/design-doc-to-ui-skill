# 05 dark-pro-tool

## Style summary

Dark professional tool UI for expert workflows. It uses compact panels, precise grids, editor-like controls, dense status information, and restrained high-contrast accents.

## Visual language

- Surfaces: near-black page background, charcoal panels, low-glare borders.
- Shape: compact rectangular panels, small radius controls, precise grid alignment.
- Type: small readable tool typography with concise labels.
- Color: near-black, charcoal, cool gray, cyan, lime, small magenta warning accent.
- Interaction cues: tool rail, inspector, layers, timeline, command palette, status chips.

## Four-end adaptation

- Web: full pro workspace with rail, canvas, timeline, and inspector.
- PC: desktop workstation shell with dense panels and status chrome.
- Mobile: focused inspection/run controls in a compact vertical workflow.
- Tablet: touch-friendly pro layout with canvas plus side panels.

## Best fit

Developer tools, creative editors, data ops consoles, observability tools, AI workflow builders, media tools, and advanced configuration interfaces.

## Constraints

Avoid poster-like neon cyberpunk styling. Keep accents purposeful, text concise, controls precise, and panels readable at small sizes.
