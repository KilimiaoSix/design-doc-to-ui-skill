# Neo Brutalist Bold

## Intent

Direct, memorable product UI for creative tools, campaign planning, task boards, hackathon products, or internal tools that intentionally use raw contrast and visible structure.

## Visual Language

- Thick black borders, hard shadows, flat saturated color blocks.
- High-contrast typography and obvious rectangular controls.
- White or near-white base with black rails and electric accent colors.
- Functional rawness: interface first, decoration second.

## Endpoint Adaptation

- Web: kanban board with sidebar, task columns, bold metric tiles, and search/filter controls.
- PC: command board with workload charts, task status, urgent cards, and calendar blocks.
- Mobile: stacked task list with bold tabs, thick cards, and bottom navigation.
- Tablet: campaign planner with split lists, kanban columns, and team panel.

## Prompt Guidance

Specify neo-brutalist product UI, not poster design. Ask for thick borders, hard shadows, flat saturated blocks, visible controls, and real task-management structures across all four endpoints.

## Negative Constraints

Avoid landing-page slogans, decorative brutalist collage, gradients, glass, soft neumorphic shadows, tiny unreadable copy, and pure poster composition.

## Risks

- High contrast and saturation can cause visual fatigue.
- Heavy borders reduce content capacity and need careful spacing.
- The style needs accessible focus states that do not rely only on color or hard shadow.
