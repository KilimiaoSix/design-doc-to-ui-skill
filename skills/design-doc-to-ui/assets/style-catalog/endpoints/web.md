# Web Endpoint Style Guidance

Use this file when generating browser-based responsive web apps.

| ID | Style | Web Guidance |
|---:|---|---|
| 01 | iOS Liquid Glass Native | Use a broad browser dashboard with translucent panels, soft blur, native-like side navigation, and calm chart cards. |
| 02 | Material 3 Expressive | Use dynamic color sections, rounded containers, expressive tabs/FABs, and large touch-friendly web controls. |
| 03 | Fluent Productivity | Use a light work hub with command bar, sidebar, task lists, activity cards, and semantic blue accents. |
| 04 | Minimal Clean SaaS | Use white surfaces, thin borders, compact KPI cards, tables, line charts, and restrained accent colors. |
| 05 | Dark Pro Tool | Use a dark workspace with toolbar, layers/sidebar, inspector cards, canvas/preview area, and dense status panels. |
| 06 | Glassmorphism Premium | Use a layered dashboard over a soft atmospheric backdrop with frosted glass cards and restrained glow. |
| 07 | Neumorphism Soft UI | Use pale surfaces with raised/sunken controls, sparse cards, simple metrics, and large tactile inputs. |
| 08 | Bento Dashboard | Use an asymmetric modular card grid with KPIs, charts, maps/status blocks, and mixed content modules. |
| 09 | Neo-Brutalist Bold | Use thick borders, flat saturated color blocks, visible grid structure, oversized buttons, and direct labels. |
| 10 | Claymorphism Playful 3D | Use friendly dashboards with puffy cards, reward widgets, soft 3D accents, and simple progress surfaces. |
| 11 | Skeuomorphic Realistic | Use textured panels, material metaphors, knobs/sliders where appropriate, and realistic tool surfaces. |
| 12 | Editorial Magazine | Use large image-led story cards, headline hierarchy, curated sections, and high-end content pacing. |
| 13 | Luxury Premium | Use refined dark or neutral surfaces, elegant spacing, premium photography, and minimal high-contrast CTAs. |
| 14 | Fintech Trust | Use account overview, portfolio charts, alert cards, clear transactions, and conservative navy/green signals. |
| 15 | Health Calm | Use appointment cards, care status, reassuring progress, soft blue/green palette, and high readability. |
| 16 | Education Playful | Use course cards, progress paths, badges, learning modules, and friendly illustrations without crowding. |
| 17 | Commerce Retail | Use product grid, filters, hero offer strip, cart summary, ratings, and clear product-first hierarchy. |
| 18 | Social Content Feed | Use feed stream, creator cards, side navigation, media previews, reactions, and balanced density. |
| 19 | AI Assistant Copilot | Use chat pane, context cards, generated artifact preview, source/citation area, and clear prompt composer. |
| 20 | Gamified Growth | Use missions, XP, rewards, streaks, campaign panels, leaderboards, and measurable progress cards. |

Web samples live in `generated-samples/*-style-board.png` as the leftmost endpoint panel.
