# Tablet Endpoint Style Guidance

Use this file when generating tablet apps or expanded touch interfaces.

| ID | Style | Tablet Guidance |
|---:|---|---|
| 01 | iOS Liquid Glass Native | Use split panes, larger glass cards, side navigation, and touch-scale charts. |
| 02 | Material 3 Expressive | Use adaptive two-column layout, dynamic color panels, larger controls, and prominent primary action. |
| 03 | Fluent Productivity | Use expanded productivity split view with navigation rail, list pane, detail pane, and task cards. |
| 04 | Minimal Clean SaaS | Use wider analytics cards, filter rail, compact table region, and readable chart layout. |
| 05 | Dark Pro Tool | Use wide workbench with inspector/sidebar, canvas, timeline/status cards, and high-contrast controls. |
| 06 | Glassmorphism Premium | Use translucent split layout with summary cards, detail pane, and restrained premium depth. |
| 07 | Neumorphism Soft UI | Use large control tiles, spacious dashboard cards, clear selected states, and strong contrast safeguards. |
| 08 | Bento Dashboard | Use expanded bento grid with more modules but maintain clear hierarchy. |
| 09 | Neo-Brutalist Bold | Use loud modular board, thick-bordered panels, clear grid tracks, and oversized interaction zones. |
| 10 | Claymorphism Playful 3D | Use activity planner with reward panel, progress cards, friendly objects, and wide touch zones. |
| 11 | Skeuomorphic Realistic | Use material-rich tablet console with realistic panels and carefully spaced controls. |
| 12 | Editorial Magazine | Use magazine split view with hero imagery, story rail, body preview, and curated sections. |
| 13 | Luxury Premium | Use immersive product/service cards, refined split layout, premium imagery, and elegant action area. |
| 14 | Fintech Trust | Use expanded portfolio charts, alerts, transaction detail, and account summary side by side. |
| 15 | Health Calm | Use split care dashboard with schedule, metrics, notes, and calming visual hierarchy. |
| 16 | Education Playful | Use classroom activity board with modules, lesson detail, reward area, and progress overview. |
| 17 | Commerce Retail | Use browsing plus checkout split, filters, product grid, and cart/detail panel. |
| 18 | Social Content Feed | Use media grid plus conversation/detail pane while keeping creator context visible. |
| 19 | AI Assistant Copilot | Use context pane, chat pane, artifact preview, and citation/source panel in a touch-friendly grid. |
| 20 | Gamified Growth | Use event map, rewards board, mission list, progress cards, and leaderboards across a wide canvas. |

Tablet samples live in `generated-samples/*-style-board.png` as the fourth endpoint panel.
