# PC Endpoint Style Guidance

Use this file when generating desktop app or desktop-width product interfaces.

| ID | Style | PC Guidance |
|---:|---|---|
| 01 | iOS Liquid Glass Native | Use a macOS-like desktop frame with translucent cards, command controls, sidebar, and spacious chart areas. |
| 02 | Material 3 Expressive | Use an adaptive desktop shell with colorful panels, large containers, FAB-like primary action, and responsive grid. |
| 03 | Fluent Productivity | Use Windows-like command bar, left rail, work lists, details pane, activity timeline, and neutral productivity surfaces. |
| 04 | Minimal Clean SaaS | Use dense but quiet tables, filters, charts, KPI rows, and precise operational controls. |
| 05 | Dark Pro Tool | Use layered panels, canvas/workbench center, inspector/sidebar, tabs, status bars, and high-density expert controls. |
| 06 | Glassmorphism Premium | Use frosted analytics cards, dark translucent surface layers, subtle gradients, and premium dashboard composition. |
| 07 | Neumorphism Soft UI | Use spacious tactile control dashboard with raised cards, soft shadows, and low-density controls. |
| 08 | Bento Dashboard | Use a large mixed-module dashboard with cards of different sizes, overview metrics, maps, charts, and tasks. |
| 09 | Neo-Brutalist Bold | Use thick bordered command boards, explicit tabs, saturated control blocks, and visible layout grid. |
| 10 | Claymorphism Playful 3D | Use friendly learning/workspace panels with 3D objects, progress cards, and large approachable controls. |
| 11 | Skeuomorphic Realistic | Use realistic hardware-console or material-rich desktop panels with visible physical metaphors. |
| 12 | Editorial Magazine | Use desktop reading/editorial workspace with hero image, story columns, curated content rail, and high contrast type. |
| 13 | Luxury Premium | Use refined discovery/booking workstation with premium imagery, dark elegant panels, and minimal actions. |
| 14 | Fintech Trust | Use portfolio workstation with charts, watchlists, risk notices, transaction tables, and conservative status colors. |
| 15 | Health Calm | Use care workspace with patient/wellness records, schedule, summary cards, and soft clinical clarity. |
| 16 | Education Playful | Use classroom/learning dashboard with lesson list, activity board, rewards, and progress analytics. |
| 17 | Commerce Retail | Use catalog management or shopping desktop with product grid, detail pane, filters, and cart/checkout region. |
| 18 | Social Content Feed | Use creator desktop feed with content grid, feed column, reactions, messages, and side navigation. |
| 19 | AI Assistant Copilot | Use copilot workspace with prompt editor, context list, artifacts, citations, and output preview. |
| 20 | Gamified Growth | Use mission-control panel with leaderboard, active missions, rewards, campaign metrics, and progress loops. |

PC samples live in `generated-samples/*-style-board.png` as the second endpoint panel.
