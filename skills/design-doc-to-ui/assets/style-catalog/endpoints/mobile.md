# Mobile Endpoint Style Guidance

Use this file when generating native phone apps or mobile-first product screens.

| ID | Style | Mobile Guidance |
|---:|---|---|
| 01 | iOS Liquid Glass Native | Use vertically stacked native cards, bottom navigation, soft glass panels, large tap targets, and restrained labels. |
| 02 | Material 3 Expressive | Use large rounded cards, dynamic color surfaces, clear top app bar, FAB/action button, and playful but legible controls. |
| 03 | Fluent Productivity | Use compact task lists, activity cards, bottom or rail navigation, and a calm blue productivity accent. |
| 04 | Minimal Clean SaaS | Use simplified KPI cards, concise list/table previews, clean filters, and one dominant action. |
| 05 | Dark Pro Tool | Use compact dark panels, quick tool controls, mini inspector areas, and high-contrast status indicators. |
| 06 | Glassmorphism Premium | Use stacked translucent cards, dark premium background, readable overlays, and minimal glowing accents. |
| 07 | Neumorphism Soft UI | Use large tactile controls, sparse content, soft shadows, and clear active states to avoid low-contrast ambiguity. |
| 08 | Bento Dashboard | Use stacked bento cards with prioritized metrics and avoid tiny multi-column details. |
| 09 | Neo-Brutalist Bold | Use chunky cards, oversized buttons, thick outlines, and very clear hierarchy. |
| 10 | Claymorphism Playful 3D | Use large friendly cards, simple progress, reward objects, mascot accents, and bottom navigation. |
| 11 | Skeuomorphic Realistic | Use realistic controls sparingly with large tap targets and avoid overcrowded hardware metaphors. |
| 12 | Editorial Magazine | Use image-led article cards, large headlines, vertical story stream, and simple reading controls. |
| 13 | Luxury Premium | Use refined booking/discovery flow, dark or neutral surfaces, premium imagery, and sparse CTAs. |
| 14 | Fintech Trust | Use account summary, spending/investment cards, transaction list, risk/status notices, and precise CTA wording. |
| 15 | Health Calm | Use daily care card, appointment reminder, simple symptom/progress check, and reassuring visual tone. |
| 16 | Education Playful | Use lesson path, progress meter, badges, friendly illustration, and one next-step action. |
| 17 | Commerce Retail | Use product detail, cart, ratings, price, variants, gallery, and high-clarity checkout CTA. |
| 18 | Social Content Feed | Use feed-first layout with media card, reactions, comments, creator profile, and bottom navigation. |
| 19 | AI Assistant Copilot | Use prompt composer, conversation cards, suggestions, compact source/context chips, and artifact preview. |
| 20 | Gamified Growth | Use quests, streak, rewards, XP bar, claim/start action, and compact mission status. |

Mobile samples live in `generated-samples/*-style-board.png` as the third endpoint panel.
